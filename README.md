# LIBRARY_ROOM
Developed a PostgreSQL Library Room Management project to analyze customers, seats, fees, discounts, and joining dates. Used SQL concepts including SELECT, WHERE, GROUP BY, JOIN, aggregate functions, subqueries, date functions, and window functions to generate meaningful business insights.

🏨 Developed a Hotel Booking Reservation System using PostgreSQL to manage guests, rooms, reservations, and payments. Implemented SQL queries using JOINs, subqueries, aggregate functions, GROUP BY, and window functions to analyze room rates, payment methods, revenue, and booking data efficiently. 📊
